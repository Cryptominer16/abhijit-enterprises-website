## 2. Brand and visual direction

Create a polished, professional local-business website. It should feel
established, helpful and reliable---not like a generic template.

-   Use a clean white/light background with a strong, tasteful primary
    colour (deep blue or navy) and a complementary warm accent.
-   Use clear typography with excellent readability on mobile.
-   Use genuine, relevant imagery: digital printing presses, printed
    brochures, wedding invitations, die-cut products, document services
    and travel.
-   Avoid clutter, excessive animation, stock-photo overload and tiny
    text.
-   Use the Abhijit Enterprises logo if supplied. Do not redraw or alter
    the logo.
-   Keep the header compact, with a visible **Call Now** and **WhatsApp
    Enquiry** action.
-   Use consistent icons, spacing, buttons and cards throughout.
-   Design all pages responsively for mobile, tablet and desktop.

## 7. Technical direction

First inspect the existing project folder and determine whether a
framework or codebase already exists. Do not overwrite working files
without checking.

If starting from scratch, use a lightweight, maintainable implementation
suitable for GoDaddy cPanel hosting. Preferred options: - HTML, CSS and
vanilla JavaScript for a simple static website; or - A build-based
framework only if the final production output can be deployed reliably
to GoDaddy cPanel.

Requirements: - Keep source code organised and readable. - Separate
content from layout where practical so service text and contact details
are easy to update. - Avoid unnecessary paid APIs and plugins. - Do not
hard-code secrets or credentials. - Provide a production build/export
process and deployment instructions. - Ensure the final website can run
on standard GoDaddy Linux/cPanel hosting. Do not assume Node.js is
available on the live hosting account.

## 8. SEO and local discovery

Implement: - Unique page titles and meta descriptions. - One clear H1
per page and logical H2/H3 hierarchy. - Descriptive image filenames and
alt text. - Canonical URLs using the preferred HTTPS domain. - Open
Graph metadata for social sharing. - XML sitemap and robots.txt. -
LocalBusiness structured data (JSON-LD) using only verified business
details. - Natural local phrases such as "Digital Printing in Akluj",
"Wedding Card Printing in Akluj" and "Document Scanning in Akluj". -
Fast loading, compressed images and minimal scripts. - Google
Maps/location link after the exact map pin is confirmed.

Do not promise search rankings or add fabricated reviews and ratings.

## 9. Performance, accessibility and quality checks

Before calling the site complete: - Test on common mobile, tablet and
desktop widths. - Check all navigation, language-switch, call and
WhatsApp links. - Check form validation and actual form delivery if
configured. - Check for spelling errors in both English and Marathi. -
Ensure Marathi text renders correctly with a suitable Devanagari font. -
Compress and resize images; use modern formats such as WebP where
supported. - Avoid layout shifts and oversized hero images. - Check
keyboard navigation, contrast, labels and focus states. - Check browser
console for errors and remove placeholder content that could be mistaken
for real information. - Run Lighthouse or an equivalent
performance/accessibility audit where available.

## 10. Delivery checklist

At completion, provide: 1. A working local preview. 2. Complete,
organised source files. 3. Production-ready website output. 4. A simple
GoDaddy cPanel deployment guide (which folder to upload to, normally
`public_html`, and how to configure HTTPS). 5. A list of details/images
still required from the owner. 6. A short guide explaining how to edit
services, prices, photos and contact details.
