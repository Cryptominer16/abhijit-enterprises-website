HOW TO PUBLISH
1. Log in to GoDaddy and open cPanel for abhijitenterprises.in.
2. Open File Manager > public_html.
3. Back up any existing website files before replacing them.
4. Upload the ZIP and extract its contents directly inside public_html.
5. Confirm index.html is in public_html (not inside an extra nested folder).
6. Enable SSL/HTTPS for the domain.
7. Test the website on mobile and desktop.
8. Submit a test enquiry and confirm it arrives at the configured email inbox.

IMPORTANT BEFORE GOING LIVE
- Verify the recipient email in contact.php. The current value is the email address previously supplied: info@abhijitenterprsies.in. Check its spelling and that it receives mail.
- GoDaddy PHP mail delivery can require domain email authentication (SPF/DKIM). If the form does not deliver, configure the domain's authenticated SMTP service or ask the hosting provider to enable it.
- The contact form currently sends enquiries by email; it does not store them in a database.
- Replace or add real project/machine photographs before launch for a stronger portfolio.
- Verify all service descriptions, address, phone number and claims before publishing.
- This is a starter site package. Domain connection, hosting access, DNS, SSL and email configuration must be completed in your GoDaddy account.
